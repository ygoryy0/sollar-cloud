# ☀️ Nuvem Solar / Sollar Cloud

Plataforma de gestão de energia solar residencial. Este é o protótipo inicial do sistema, focado em previsão de consumo, geração baseada no clima e gestão de faturas.

## 🚀 Funcionalidades
- Previsão de Geração Solar (baseada no tempo)
- Previsão de Consumo e Faturamento Mensal
- Balanço Energético (Autoconsumo vs. Rede)
- Assistente Inteligente para o morador

## 🛠️ Tecnologias (MVP)
- HTML5, CSS3, JavaScript (Vanilla)
