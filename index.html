Como funciona a previsão

Transparência total sobre os dados

1. Fonte meteorológica: usamos dados de irradiância solar e temperatura previstos para a sua localização (via API Open-Meteo).

2. Modelo físico: convertemos a irradiância em potência elétrica considerando a potência instalada do seu sistema (5,4 kWp), inclinação (20°), orientação (Norte) e eficiência do inversor.

3. Margem de erro: a previsão tem margem de ±15% para os próximos 3 dias e ±25% para os dias 4-7. Condições climáticas imprevistas podem alterar o resultado.
